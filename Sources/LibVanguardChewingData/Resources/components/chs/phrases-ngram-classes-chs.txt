#==================================
# 先锋 n-gram 前验词库的同类清单（简体中文）。
# -------------------
# 本档把「同一语法类别的一批词」集中成一行，供 `phrases-ngram-chs.txt` 以类名引用。
# 产制端（VCDataBuilder）在解析 n-gram 表时，会把类名展开成逐条成员：
# 一条模板列即可生成整族 n-gram，不必逐词抄写。
#
# 每行两栏，以 Tab（U+0009）分隔；以 # 起首的行与空行一律忽略：
#   第 1 栏：类名（含角括号本身，故 n-gram 表直接写 `<处所名词>` 即可）。
#   第 2 栏：成员词值，各词以空格分隔。
#
# 展开规则（实作见 Collector_Ngram.swift）：
#   - 词值栏与前验词链栏都可引用类名；两处同时引用时取笛卡尔积。
#   - 词值栏为类名时，该列的读音栏无意义（写 `-`），改以成员词在 unigram 表中的
#     读音入库；查无读音的成员一律略过，不臆造读音。
#   - 成员清单只是「种子」：加词即生效，不必改 Swift 程式码。
#
# 本档的类别是「起步集」，不是语法学上的穷举；成员是否够用，由组句结果回馈。
#==================================
