#==================================
# 先锋 n-gram 前验词库的同类清单（简体中文）。
# -------------------
# 本档把「同一语法类别的一批词」集中成一行，供 `phrases-ngram-chs.txt` 以类名引用。
# 产制端（VCDataBuilder）在解析 n-gram 表时，会把类名展开成逐条成员：
# 一条模板列即可生成整族 n-gram，不必逐词抄写。
#
# **类名一律用英文 token，繁简两档共用同一套**：解析逻辑不必为语系维护两套类名，
# 繁体／简体之别只落在「成员」上（见下）。
#
# 每行两栏，以 Tab（U+0009）分隔；以 # 起首的行与空行一律忽略：
#   第 1 栏：类名（含角括号本身，故 n-gram 表直接写 `<PLACE_NOUN>` 即可）。
#   第 2 栏：成员词值，各词以空格分隔。
#
# 起步集之三类：
#   <PLACE_NOUN>     处所名词——「在」之后接者。
#   <OBJECTIVE_VERB> 他动词（及物动词）——「再」之后接者。
#   <SELF_VERB>      自动词（不及物动词）——「再」之后接者。
#
# 展开规则（实作见 Collector_Ngram.swift）：
#   - 词值栏与前验词链栏都可引用类名；两处同时引用时取笛卡尔积。
#   - 词值栏为类名时，该列的读音栏无意义（写 `-`），改以成员词在 unigram 表中的
#     读音入库；查无读音的成员一律略过，不臆造读音。
#   - 成员清单只是「种子」：加词即生效，不必改 Swift 程式码。
#
# 本档的类别是「起步集」，不是语法学上的穷举；成员是否够用，由组句结果回馈。
#==================================
<PLACE_NOUN>	这里 那里 哪里 家 学校 公司 店 房间 厕所 厨房 办公室 车上 路上 楼上 楼下 台北 台中 高雄
<OBJECTIVE_VERB>	说 看 读 写 吃 喝 买 卖 问 找 用 学 做 见 听 拿 给 教 开 关
<SELF_VERB>	来 去 走 睡 玩 等 想 试 哭 笑 坐 站 跑 飞 死 病 活
