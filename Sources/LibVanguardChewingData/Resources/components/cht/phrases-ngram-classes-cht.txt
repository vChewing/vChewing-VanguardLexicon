#==================================
# 先鋒 n-gram 前驗詞庫的詞類清單（繁體中文）。
# -------------------
# 本檔把「同一語法類別的一批詞」集中成一行，供 `phrases-ngram-cht.txt` 以類名引用。
# 產製端（VCDataBuilder）在解析 n-gram 表時，會把類名展開成逐條成員：
# 一條模板列即可生成整族 n-gram，不必逐詞抄寫。
#
# **類名一律用英文 token，繁簡兩檔共用同一套**：解析邏輯不必為語系維護兩套類名，
# 繁體／簡體之別只落在「成員」上（見下）。
#
# 每行兩欄，以 Tab（U+0009）分隔；以 # 起首的行與空行一律忽略：
#   第 1 欄：類名（含角括號本身，故 n-gram 表直接寫 `<PLACE_NOUN>` 即可）。
#   第 2 欄：成員詞值，各詞以空格分隔。
#
# 起步集之三類：
#   <PLACE_NOUN>     處所名詞——「在」之後接者。
#   <OBJECTIVE_VERB> 他動詞（及物動詞）——「再」之後接者。
#   <SELF_VERB>      自動詞（不及物動詞）——「再」之後接者。
#
# 展開規則（實作見 Collector_Ngram.swift）：
#   - 詞值欄與前驗詞鏈欄都可引用類名；兩處同時引用時取笛卡兒積。
#   - 詞值欄為類名時，該列的讀音欄無意義（寫 `-`），改以成員詞在 unigram 表中的
#     讀音入庫；查無讀音的成員一律略過，不臆造讀音。
#   - 成員清單只是「種子」：加詞即生效，不必改 Swift 程式碼。
#
# 本檔的類別是「起步集」，不是語法學上的窮舉；成員是否夠用，由組句結果回饋。
#==================================
<PLACE_NOUN>	這裡 那裡 哪裡 家 學校 公司 店 房間 廁所 廚房 辦公室 車上 路上 樓上 樓下 台北 台中 高雄
<OBJECTIVE_VERB>	說 看 讀 寫 吃 喝 買 賣 問 找 用 學 做 見 聽 拿 給 教 開 關
<SELF_VERB>	來 去 走 睡 玩 等 想 試 哭 笑 坐 站 跑 飛 死 病 活
